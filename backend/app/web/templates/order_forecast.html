How "Remaining now" and "Cover" work
ⓘ

Remaining now — type what's physically left (in the shown unit; Baby Corn also takes packets). The row then uses remaining ÷ daily usage for a real runout date, overriding the cadence guess. Leave it blank and the row falls back to last purchase + average gap between orders.

Cover = days remaining as of today at the implied usage rate. Usage rate comes from ~a month of purchases, so treat it as a prompt to check stock, not gospel — and correcting a wrong quantity is as simple as entering what's actually on the shelf.
