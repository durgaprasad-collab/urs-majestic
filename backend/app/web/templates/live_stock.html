Chrome helper{% if helpers %} · {{ helpers|length }} set up{% else %} · not set up yet{% endif %}

A small Chrome add-on on the restaurant PC opens Petpooja's item report in the background, refreshes it every ~10 minutes while you're open, and sends the rows here. It needs a helper code from this page.

  1. On the PC, open Chrome → chrome://extensions → turn on Developer mode → Load unpacked → choose the live-feed-ext folder (from the project folder).
  2. Press Create helper code below and copy the code (it's shown once).
  3. Click the add-on's icon, paste the code, check Opens / Closes (default 12:00 PM to 1:00 AM) and press Save & test.
  4. Stay signed in to Petpooja in that Chrome. During opening hours the add-on opens a small pinned tab on the item report and refreshes it by itself; outside those hours it does nothing.
