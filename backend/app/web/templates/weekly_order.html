How these numbers are computed
ⓘ

Recommended qty — the model's raw forecast of demand over the next 7 days (the best of four models, picked by lowest backtested error: weekday-seasonal, recent-trend EWMA, or one of two ML models; unmapped items fall back to purchase cadence).

Usage — recommended qty spread evenly across the 7 days, as a daily rate.

Existing stock — your latest Stock Log count, only used if it was counted in the same unit as the ingredient. Otherwise you'll see "Count needed".

To procure = recommended qty + a one-day safety buffer (bigger when the model's error rate is higher) − existing stock − anything already inbound from an approved order, rounded up to the ingredient's order increment.

URGENT — existing stock ÷ usage rate is under 3 days, the same cutoff Order Forecast uses. These items are pinned to the top so nothing that's genuinely close to running out gets buried in the full week's list.
